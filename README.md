# XMind Capital AI Terminal

An intelligent, autonomous portfolio management platform powered by AI agents, **Chainlink Custom Runtime Environment (CRE)**, and **Avalanche**. 

XMind Capital allows users to deposit funds into ERC-4626 standard vaults, which are then autonomously managed by AI agents. These agents analyze market conditions, evaluate risk, and execute mathematically constrained trades using on-chain signature verification to ensure safety.

## 🌟 Key Features

### 1. **Autonomous AI Portfolio Management**
- AI agents run inside a simulated **Chainlink CRE** environment (a secure, off-chain sandbox).
- The AI evaluates vault balances, live market prices, and risk metrics before making any trading decision.
- Trades are cryptographically signed using EIP-191.

### 2. **Model Context Protocol (MCP) Server**
- The AI's "brain" is decoupled from its "senses". Our MCP server acts as the Bloomberg Terminal for the AI.
- Exposes tools like `get_full_context` to feed the AI real-time data efficiently.
- Compiles the AI's intent (e.g., "10% to AVAX") into a deterministically encoded, signed transaction payload.

### 3. **Smart Contract Guardrails (Avalanche Fuji)**
- **AgentVault (ERC-4626)**: User capital sits here. It tracks Net Asset Value (NAV) dynamically.
- **RiskValidator**: A stateless on-chain guardrail that enforces a strict 40% liquidity buffer, ensuring the AI can never lock up all user funds.
- **CREIntegration**: Verifies the EIP-191 signatures generated by the AI before executing any trade against the vault.

## 🚀 Getting Started

### 1. Smart Contracts
Deployed on Avalanche Fuji testnet using Hardhat.
```bash
cd contracts
npm install
npx hardhat compile
npx hardhat run scripts/deploy-testnet-mocks.js --network avalancheFuji
```

### 2. MCP Server
Runs locally using Cloudflare Wrangler.
```bash
cd xmind-mcp
npm install
npx wrangler dev --port 8787
```

### 3. Chainlink CRE Simulation
Simulates the off-chain secure execution environment.
```bash
cd xmind-cre
cre workflow simulate xmind-workflow --target staging-settings
```

### 4. Frontend Application
```bash
cd frontend
npm install
bun dev
```

Visit `http://localhost:3000` to interact with the platform.
